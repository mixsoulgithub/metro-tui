# metro

终端里的地铁线路图(杭州 / 上海 / 成都 / 深圳):`ratatui` + ASCII,一条线路一种颜色。
不带参数启动时先出选城市的界面;`--city shanghai` 可以直接进某个城市。

同一套技术栈和 `slay-the-spire/` 一样(ratatui 0.30 + crossterm 0.29 + 24 位真彩)。

## 两种画法

默认是**示意图**:从真实经纬度出发做放松,让每条线上的相邻站间距差不多,线的走向
吸附到横、竖、45 度上,同时把站点互相推开至少一格 —— 排出来的疏密像一张地铁线路图,
不会有市中心挤成一团、或者一条大站快线拉出十公里直线的情况。相对方位仍然是真实的:
临安在西北、萧山机场在东南、富阳支线往西南、大江东往东。

`--real`(或界面上按 `r`)切到**真实地理**:按等距圆柱投影直接从经纬度落图,纵向按
"字符格高约等于宽的两倍"修正。站密的地方会挤在一起,长站距的大站快线会拉出很长的直线,
但位置就是实际位置,适合对着地图看。

两种画法都不做"哪些站可达"的高亮 —— 图上哪儿都能去。

- 普通站 `○`,换乘站 `◎`(白色加粗),颜色都是那条线的颜色
- 线路是正交走线:只用 `─` `│` 两种笔画,拐弯处 `╭` `╮` `╯` `╰`
  (这一套和 lazygit 的提交图一个路子,字符表用 `uni s box` 查的)
- 两条线在**非站点处**交叉 = 一条从另一条下面过:占住那一格的那条线照自己的形状画,
  另一条在这一格断一格。所以 `├` `┤` `┬` `┴` `┼` 基本只会出现在站点上(站点画成
  `○`/`◎`),图上不会再出现"看着像换乘、其实那儿什么都没有"的十字
- 每条边要么直连,要么拐一个直角.拐哪一边不是各自随意决定的:先看这一站在整条线上
  是"竖着进"还是"横着进"(前后两站都在它北边/南边就竖着进,都在东边/西边就横着进),
  于是"下去再上来"这种折返会走**同一列**,不会绕着站点围出一个方框;
  再不然才看哪种拐法踩到的**别的线**的格子少(复用自己的走廊不算代价)
- 一格只能有一种颜色.冲突时**光标所在站的线路优先**:两条线的笔画撞在同一格、
  或者一个换乘站连了多条线,颜色都让给光标那条线 —— 按方向键沿线走的时候,
  顺着颜色就能把自己这条线整条连起来看(光标那条线不经过的换乘站保持亮白)
- 线路端点站常驻站名;窗口大到站距在屏幕上拉开 4 格以上,会自动把能放下的站名都标出来,
  按 `b` 可以强制全标或全不标 —— 站名只写在空位上,挤的地方自动跳过
- 右侧是图例,底部状态行是光标所在站、经过的线路、相邻站和按键提示

## 构建与运行

```bash
cd graph
cargo build --release
./target/release/metro              # 先选城市
./target/release/metro --city chengdu
```

建议终端别太小:整幅图 97 km x 51.5 km,200x50 左右正好用满;

```
metro [options]
  --file <path>  读取线路图 .dot(默认内嵌 docs/hangzhou-subway.dot)
  --dump         渲染一帧到 stdout(真彩 ANSI)后退出,可配合 --size
  --size <WxH>   --dump 的画布大小(默认 200x50)
  --labels       一上来就把所有站名标出来(等于按 b)
  --real         按真实经纬度画(默认是示意图,按 r 可以随时切)
  --at <站名>    开局把光标停在那一站
  --find <词>    开局就搜一遍(站名/拼音/首字母,或线路号)
  -h, --help     显示帮助
```

`--dump` 是纯文本输出,直接 `less -R` 看,或者重定向成文件:

```bash
./target/release/metro --dump --size 220x55 | less -R
```

## 键位

| 键 | 作用 |
| --- | --- |
| `h` `j` `k` `l` / 方向键 | 朝那个方向挑**离得近、而且方向正对着的那一站**(分数 = 屏幕距离 + 2 倍横向偏斜,所以不会挑到斜着挨着的那一站):距离和方向都按屏幕格子算 —— 眼睛看到哪站在那个方向、哪站近就走哪站,所以换个终端尺寸、或者切到示意图/真实视图,答案都可能不同;那个方向 45 度锥形以外的站不算。唯一的例外是聚焦某条线时(`/1` 或 `V`):那条线上的站容忍 2 倍距离优先,于是方向键基本就在沿那条线走(自动跟着平移视图) |
| `H` `K` / `J` `L` | 沿线走一站:**`H` `K` 是上一站,`J` `L` 是下一站** —— 只按线路自己的站序,和真实方位、屏幕方向都无关(换乘站上按 `H` 就是这条线的上一站,不会拐到别的线)。站上同时有好几条线都能走时弹一个列表:数字或 `j` `k` 选、回车走、`esc` 取消 |
| `+` `-` | 放大 / 缩小 |
| `0` | 复位成整幅图(缩放和位置一起复位) |
| `空格` `z` | 把光标那一站挪到画面正中(平滑滑过去) |
| `f` | 把聚焦的线路(没聚焦就是当前站那条线)整条铺满画面 |
| `b` | 开关站名标注 |
| `/` | 搜站名 / 拼音 / 首字母(比如 `wulin`、`wlgc`);输入纯数字则高亮那条线的全部车站 |
| `5l` `3j` | 数字前缀:一次性挪好几站(纯键盘长途旅行用) |
| `Ctrl-d` `Ctrl-u` | 半屏往下 / 往上跳一站(比一站一站按快得多) |
| `Ctrl-o` `Ctrl-i` | 回到上一个 / 下一个"跳过的站"(搜索、鼠标点、半屏跳都会记进去;`Tab` 就是 `Ctrl-i`) |
| `n` `N` | 下一个 / 上一个命中的站 |
| `V` | 聚焦当前站所在的线路(换乘站一次聚焦几条,和搜这几条线的线路号一个效果,之后按 `n` 能一站站看过去);这一站的线已经在聚焦里,这一下就是取消 |
| `r` | 在示意图与真实地理之间切换 |
| `?` | 键位速查浮层(任意键关掉) |
| 鼠标 | 左键点站;左键按住拖动平移地图;滚轮缩放;`Ctrl`+滚轮上下平移(`Shift` 左右) |
| `:` | 命令行(调试):`:cycle <倍数>` 同线那一档允许比最近的远多少(默认 2.0);`:side <倍数>` 横向偏斜算几倍距离(默认 2.0,调小就更认"屏幕上最近") |
| `q` / `esc` | 回到选城市界面(`--city` 进来也一样);在选城市界面里按才退出 |
| 鼠标左键 | **单击**就生效:地图区里点哪儿,光标就跳到离点击点最近的那一站(图例和状态行上的点击不算,点它们不会乱跳)。选城市界面:点一下选中某城,点已选中的那行就进去。在 tmux 里跑要 `set -g mouse on`,不然鼠标事件到不了程序 |

当前那一站是**实心**的(普通站 `●`、换乘站 `◉` —— 图上其它站是空心 `○` `◎`),
颜色还在平时那个亮白和红色之间来回闪:曲线是**正弦**(0 起、1 顶、平滑停住,不生硬),
**节奏按心跳的频率** —— 一个来回 0.8 秒(约 75 下/分),所以一眼就能找到"我在这儿"。
闲着的时候按 ~30fps 重画(移动中 60fps),上海那张图实测 4.7% CPU。

移动是平滑的:视图中心每帧朝目标挪掉剩余距离的 22%(约 60fps 重画,到位后吸附到不足半格),
所以方向键把光标带出视野、或者按 `空格` 居中时,画面是滑过去的,不是硬跳。
`0` 复位和 `+` `-` 缩放是立即生效的。

## 示意图是怎么排的

`src/layout.rs` 里是一遍确定性的放松(没有随机数),从真实坐标出发:

1. 先把经纬度铺进 192x48 的格子当初始位置(`--real` 那套形状);
2. 每轮迭代四件事:相邻站之间的弹簧(目标间距 2.6 格)、方向吸附(把每条边掰向横、
   竖或 45 度)、把"一条线上连着三站"往共线拽(画出来才有长走廊,少些一站一折角;
   中间站是**按线路**算的 —— 换乘站对每条经过它的线都是中间站,一样要拉直)、
   站点之间的斥力(短于 2.6 格就推开),再叠一个跟着布局一起缩放的"锚",只负责保住
   相对方位,不把地理上稀疏的地方硬撑大;
3. 600 轮之后取整到格子:一格一站,占了就按同心环往外找最近的空格;
4. 收尾反复做三件事,直到都改不动为止 —— 把边掰直、把相邻站拉开、把**任意**两站
   分开至少一格(同一格也不行)。三个动作都只挑"自己和周围八格都空着"的格子来挪,
   所以谁最后跑都不会毁掉别人摆好的走向。
5. 规格留一点余量:200x50 的窗口下整幅图是"放大"铺满的,而不是被压着塞进去 ——
   压着塞会让四舍五入把两站并到相邻格。

收尾这一步是市中心那团的解药:只保证"线路上的相邻站"是不够的,不同线路的站挨在
一起照样糊成一团。现在的效果(200x50 屏):示意图里没有一站和别的站贴在同一格或
隔壁格,站与站最近的中位距离是 2 格;而真实地理版有 231 站是贴着别人的。

规格固定成 192x48,换窗口只是把同一张图放大缩小,图本身不会跳。

## 数据是怎么来的

文档里只有"线路 + 站点顺序",没有坐标。整条链路:

```
docs/hangzhou-subway.md        线路与站点顺序(人工整理,杭州)
        |
        |  tools/md2dot.py      站名去 OSM 找真实坐标,缺失的按线路顺序插值
        v
docs/hangzhou-subway.dot       站点(带 pos)+ 相邻站之间的边(带线路色)
        |
        |  include_str!         编译进程序
        v
src/dot.rs -> src/map.rs -> src/ui.rs   投影 + ASCII 绘制
```

`md2dot.py` 的做法:

1. 站名去掉括号/空格后去 `data/osm_stations.json`(OSM 的 `station=subway` 节点)里查,
   同名有多个节点就取离这条线最近的那个;
2. 一条线路的所有 OSM 关系按 150 米并成一张 stop 图(节点=物理站点,边=关系里相邻的
   stop)。文档里相邻的两站在图上走最短路,**路上经过的站会补进来** —— 所以 6 号线
   富阳支线会接在美院象山、3 号线两条支路(吴山前村 / 石马)也按真实走向接;
3. OSM 关系常缺端点站(比如 2 号线的良渚、16 号线的九州街),这些站直接用站点节点自己的
   坐标,只要它贴着这条线的轨道(400 米内);实在没有名字的站(比如萧山国际机场没有
   独立节点)按关系的 stop 顺序取;
4. 都没有的站,在前后两个已知站之间沿线路按距离均分插值;
5. 颜色抄线路关系上的 `colour` 标签。

想重新抓一遍数据(需要能上 Overpass):

```bash
python3 tools/fetch_osm.py            # 写 data/osm_routes.json + data/osm_stations.json
python3 tools/md2dot.py               # 重新生成 docs/hangzhou-subway.dot
cargo build --release                 # 重新编译(dot 是 include_str! 进来的)
```

`fetch_osm.py` 按 0.06 度小格分开查(Overpass 对大结果会 504),每格结果缓存在
`.cache/` 里,断了重跑不会白干。

## 一点提醒

`○` `◎` `─` 这些字符的东雅宽度是"不确定"(ambiguous):宽字符终端 + CJK 字体会把它们
画成两格宽,那样整幅图会错位。用等宽字体、locale 不是 CJK 的终端就没问题。

## 搜索与聚焦

`/` 之后打什么都行:

- 中文:直接匹配站名(前缀 > 包含)
- 拼音:`wulin` 这种,匹配整串拼音(前缀 > 包含);`ü` 写 `v` 或 `u` 都行
- 首字母:`wlgc` → 武林广场
- 多音字:字典里一个字的几种读音都会列出来,`changhe` 也能搜到 长河
- 纯数字:不当站名,当成线路号 —— **高亮这条线的全部车站**(`6` 连 6 号线支线一起),
  配合 `n` 可以一站一站看过去

命中的结果是**聚焦**:命中涉及的那几条线(数字输入就是那几条线)保留原本的颜色,
图上其余的站和笔画全部压暗成灰色,一眼就能顺着颜色看清是哪条线。回车确定、Esc 取消、
`n` 在命中的站之间跳。

聚焦期间:

- **颜色优先级一直归聚焦那条线** —— 光标挪到别的线上也不变,画面不会跟着光标变色;
- **方向键优先走这条线**(聚焦线上的候选远 2 倍以内都走它),
  于是 `/1` 之后按 `h` `j` `k` `l` 基本就是沿着 1 号线一站站走。

想单独细看某一站:按 `空格` 把它挪到画面正中,再按 `+` 放大。

上海 / 成都 / 深圳是"几号线,名称,经度,纬度"的 csv(一行一站,一条线路一个块),
一个命令就出图:

```
tools/csv2dot.py --city shanghai     docs/shanghai-subway.md -> docs/shanghai-subway.dot
tools/csv2dot.py --city chengdu      docs/chengdu.md
tools/csv2dot.py --city shenzhen     docs/shenzhen.md
tools/csv2dot.py --all               三个一起
```

块里的站序就是在线路上的顺序;换乘站在多块里重复出现,按站名并成一个节点。
线路颜色能从 `data/osm/<slug>_routes.json` 的 `colour` 标签拿到就用真的(上海有),
没有就按序号取调色板(成都 / 深圳)。

支线有三种写法,csv2dot 都认,而且每一处都会打印出来:

- **单独成块**(推荐,深圳 `6号线支线`、上海 `11号线支线`、成都 `1号线支线` 都这么写):
  块的第一行写枢纽站,支线块里的坐标可以空着 —— 同名站会从别的块里取坐标,
  同名站还会并成同一个节点,于是枢纽自动接上;
- **写在主线块里**(上海 `5号线` 东川路 那头、`10号线` 龙溪路 那头):枢纽没有重复写,
  按几何认出岔口把那一跳接回去,并打印"接回 xx";
- 认不出来又长得离谱的(超过中位站距 12 倍)会**丢掉那条边并打印出来**,那一段先单放成一块 ——
  与其画一条横贯全图的假线,不如留个缺口让人去核对文件。机场快线那种十几公里没站的真长区间
  不够这个倍数,不会误伤。

也可以完全靠 OSM 关系生成(需要能连上 Overpass):

```
tools/fetch_city.py --city shanghai   抓 data/osm/shanghai_*.json
tools/osm2dot.py    --city shanghai   关系里 stop 成员的顺序就是站序 -> dot
```

仓库里带 4 座人工校对过的城市(杭州 / 上海 / 成都 / 深圳),`metro` 启动时列在选城市界面里。

加新城市只改一处:`tools/cities.py` 里的表(slug / 中文名 / OSM 的 network 标签 / bbox),
几个脚本(fetch_city、osm2dot、csv2dot)都读它。`networks` 留空表示"bbox 内的
`route=subway` 关系全要"(海外城市常用 —— OSM 里不一定按运营方打标签);写了的就按标签筛。

```
python3 tools/build_cities.py --all              # 一条命令批量建:抓 OSM -> 生成 dot(断点续跑)
python3 tools/build_cities.py --city wuhan       # 只建某几座
python3 tools/build_cities.py --all --done list  # list 里列出的城市跳过(一行一个 slug)
```

Overpass 时通时断:脚本启动时会先探一遍几个镜像(15 秒小查询),只留能应答的,
之后失败的查询换镜像、退避重试。本机有代理的话直接给环境变量,脚本走 urllib 会自动识别:

```fish
set -x https_proxy http://127.0.0.1:<端口>
python3 tools/build_cities.py --all
```

失败的城市重跑同一条命令就行(抓到的站点分格有缓存、会跳过)。
建好的 `.dot` 放在 `docs/`,**不用重新编译**:`metro` 启动时会列出这些现成的线路图,
`--city <slug>` 也能直接打开。想固定进二进制就在 `src/city.rs` 的 `CITIES` 里加一行 `include_str!`。

拼音表是 pypinyin 的字典筛出来的(只留用到的字),落在 `data/pinyin_chars.txt`,
改了城市之后跑 `tools/fetch_pinyin.py` 重新生成;`--extra-dir <目录>` 可以再把别的目录
(及其子目录里的 `.md`/`.dot`)一块儿扫进来,`-o` 指定写到哪。

## 数据来源

- 站点坐标、线路颜色:OpenStreetMap 的 `route=subway` 关系与 `station=subway` 节点,
  (c) OpenStreetMap contributors,ODbL 许可。
- 线路与站点顺序:杭州来自 `docs/hangzhou-subway.md`(人工整理),
  上海 / 成都 / 深圳 来自同一批 OSM 关系里 stop 成员的顺序。

## 已知取舍

- 一条线自己画的笔画不该围出空格(视觉上就是个方框)。路由上有两条约束:折线不从**别的站点**上穿过去;
  拐弯时也不许把自己绕成环(两端在这条线已画的笔画里本来就连着、这一笔又要踩新格子时换一种拐法)。
  杭州 2 号线还有 1 处、9 号线还有 2 处小圈,是最后一段"直线"封的口(直线段没有拐法可选),
  要彻底消掉得做全局重排。
- 市中心站距常常不到一格,缩到最小会挤在一起;`+` 放大看局部,或者把窗口开大。
- 换乘站里如果有几条线各有一个自己的站体,OSM 上是不同节点,这里按"同名且在线附近"合并成一个。
- 用 `#` 表达换乘站后,原本经过它的线路颜色在那一点会断开,这是终端一格一色的限制。

